# Data Management System

My first Python project.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Features
- Explored the Titanic dataset.
- Checked missing values and handled data cleaning.
- Analyzed passenger distribution.
- Created a new feature called Family Size using SibSp and Parch.
- Compared the average age of survivors and non-survivors.
- Analyzed survival rates based on:
- Gender
- Passenger Class
- Embarkation Location
- Used GroupBy operations for data analysis.
- Created visualizations to understand the results.
